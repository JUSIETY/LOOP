# LOOP · AI 분리배출 챌린지

카메라로 폐품을 확인하고 배출 방법을 고르는 한국어 체험 부스입니다. 참가자의 점수와 자주 틀리는 품목을 확인하고, 직접 모은 이미지로 인식 성능을 비교할 수 있습니다.

- **사이트:** https://jusiety.github.io/LOOP/
- **실행:** `npm ci` 후 `npm run dev:pages`
- **배포 파일 갱신:** `npm run build:pages && npm run verify:pages` 후 `docs/`와 소스를 함께 커밋합니다.
- **GitHub Pages 설정:** `main` 브랜치의 `/docs` 폴더를 배포합니다.

화면과 모델은 GitHub Pages에서 제공하고, 여러 기기의 행사 기록은 기존 공개 API 서버에 저장합니다. 연습 모드와 직접 모은 이미지 특징은 현재 브라우저에 저장됩니다. 기존 사이트의 운영자 권한과 브라우저 데이터는 다른 도메인으로 자동 이전되지 않습니다.

AI 인식 후보는 참가자가 확인합니다. 품목의 숨은 재질·오염 상태와 실제 수거 기준을 사진만으로 확정할 수는 없습니다. 안산시·한양대 ERICA 행사에서는 운영자가 현장 수거 기준을 확인하고 부스 설정의 정답 안내를 맞춰 주세요. 모델별 데이터 출처·라이선스·평가 보고서는 `public/models/`에 있습니다.

자세한 배포 방법은 [PAGES.md](PAGES.md), 데이터 준비와 학습 명령은 [scripts/training](scripts/training)을 참고하세요. 기존 서버는 `npm run build`로 별도 빌드합니다. 비밀 키, 운영자 토큰, 참가자 기록은 저장소에 포함하지 않습니다.

용도 확인이 필요하거나 인식이 불확실하면 **ChatGPT 웹 확인** 카드를 제공합니다. 사진 복사(지원하지 않으면 PNG 저장) → ChatGPT에 직접 첨부 → JSON 답변 붙여넣기 → 품목 후보 적용 순서입니다. API 키를 사용하지 않으며, ChatGPT 로그인·무료 이용 한도가 적용될 수 있습니다. 사진 자동 첨부나 답변 자동 수신은 지원하지 않습니다. 외부 답변은 배출 정답이나 점수를 바꾸지 않습니다.
