# LOOP · AI 분리배출 챌린지

카메라로 폐품 후보를 인식하고, 참가자가 배출 방법을 선택하는 학교 부스용 웹앱입니다.

## 바로 운영하기

1. **부스 설정**에서 행사명, 학교·지역, 기준 출처를 입력합니다. 기본 10개 정답·설명은 체험용 예시입니다. 실제 수거함과 담당자 기준에 맞게 수정하고 확인 표시를 저장하세요.
2. **행사 만들기**를 누릅니다. 이 기기가 운영자 기기가 됩니다. 같은 행사 코드를 입력하거나 행사 QR로 들어온 기기는 같은 점수·통계를 사용합니다. 운영자 권한은 이 브라우저의 저장소에 보관됩니다.
3. **AI 실험실**의 **AI 모델 미리 준비**로 행사 전 로딩을 확인하세요. 모델은 앱에 포함되어 있고 API 키가 필요 없습니다. 사이트 로드와 행사 기록 동기화에는 인터넷 연결이 필요합니다.
4. 카메라를 켜거나 사진을 업로드합니다. AI 후보를 확인한 뒤 5개 품목의 배출 방법을 선택하세요. 카메라를 사용할 수 없을 때는 **품목 직접 선택**을 사용합니다.
5. **라이브 보드**를 전시 화면으로 띄웁니다. 행사 데이터는 5초마다 갱신됩니다. 오답 횟수·오답률·가장 많이 고른 오답·익명 순위·기준 버전별 정답률을 확인할 수 있습니다.
6. **부스 가이드**에서 행사 QR 안내판을 인쇄하거나 PNG로 저장합니다. QR에는 현재 행사 코드가 포함됩니다.
7. 운영자 기기의 **CSV 내보내기**로 응답 기록을 내려받습니다. 안내를 바꾸고 새 참가자부터 다음 기준 버전으로 비교하세요.

첫 화면의 **연습 모드**는 브라우저에만 기록합니다. 실제 행사 운영은 행사를 만들어야 여러 기기의 기록을 함께 모을 수 있습니다. 연습 기록은 행사 기록과 별도로 보관합니다. 진행 중인 도전은 같은 브라우저를 새로 열어도 이어집니다.

## 직접 수집한 이미지로 인식 성능 비교

- MobileNet v2 alpha 1.0이 1280차원 이미지 특징을 추출합니다.
- 학습 이미지를 최근접 이웃(k-NN) 비교 데이터로 사용합니다. 신경망 가중치를 새로 학습하는 방식은 아닙니다.
- 품목별로 다른 물건·배경·조명·각도에서 학습 10장 이상과 별도로 찍은 평가 3장 이상을 권장합니다.
- 같은 파일은 SHA-256으로 중복 차단합니다. 연속 촬영 등 비슷한 이미지도 학습·평가 양쪽에 나눠 넣지 마세요.
- **성능 비교 실행**은 같은 평가 이미지에서 기본 ImageNet 분류와 내 데이터 k-NN의 정확도·품목별 결과·혼동 결과를 계산합니다. 인식 불가도 오답으로 포함합니다.
- 기본 모델은 폐기물 전용 모델이 아닙니다. 오염·재질·지역 기준을 판정할 수 없으므로 참가자·진행자가 후보를 확인합니다. 표시 유사도는 정답 확률이 아닙니다. 실물 인식률은 실제 평가 이미지로 측정해야 합니다.
- 이미지 특징 데이터는 IndexedDB에 저장합니다. 원본 사진과 카메라 영상은 서버에 보내지 않습니다. 다른 기기로 옮길 때 JSON 내보내기/가져오기를 사용하세요.

## 로컬 실행

Node.js 22.13 이상이 필요합니다. 포함된 백엔드 통합 테스트는 Node.js 23.7 이상에서 실행합니다.

```sh
npm ci
npm run build
npm run db:local
npm run dev
```

터미널에 표시된 localhost 주소를 엽니다. 카메라는 HTTPS 또는 localhost에서 동작하며 브라우저 권한이 필요합니다. 일반 HTTP의 휴대폰 LAN 접속에서는 카메라가 제한될 수 있으므로 실제 부스에서는 배포된 HTTPS 주소를 사용하세요.

`db:local`은 로컬 마이그레이션만 적용합니다. 운영 데이터베이스는 Sites 배포 과정에서 별도로 관리합니다.

## 검증

```sh
npx tsc --noEmit
node scripts/verify-backend.mjs
npm run build
```

백엔드 검증은 메모리 SQLite에서 실제 API 코드를 실행합니다. 서버 채점, 점수 변조 무시, 중복/순서 오류, 운영 권한, 5문제 완료, 설정 버전 보존, 통계와 CSV 권한을 검사합니다.

## 구성과 보관

- `components/ChallengeApp.tsx`: 퀴즈, 라이브 보드, 행사 설정, QR 안내판
- `components/AiLab.tsx`, `lib/vision.ts`: 이미지 수집·특징 저장·평가
- `app/api/rooms/`: 행사 생성·참가·채점·통계 API
- `db/schema.ts`, `drizzle/`: D1 데이터베이스와 마이그레이션
- `lib/content.json`: 공식 출처를 포함한 기본 예시 콘텐츠
- `public/models/mobilenet/`: 공식 MobileNet 가중치와 SHA-256 출처 기록

별명에 실명·학번을 입력하지 마세요. 행사 모드의 별명·응답·점수·기준 버전·응답 시각은 서버에 저장되며, 상세 CSV와 설정 변경은 운영자 키로 제한됩니다. 공개 사이트의 참여 화면·행사별 집계·별명 순위는 링크를 가진 참가자가 볼 수 있습니다.

운영자 권한을 보관한 브라우저 데이터를 삭제하면 그 기기의 관리 권한도 사라집니다. 행사 종료 전에 필요한 CSV와 AI 특징 데이터를 내려받으세요. 실제 오염 폐품 대신 세척한 모형을 사용하고, 준비한 상자·물품은 다음 행사에 재사용하세요.
